# Dungeon Crawl - Burg's Edition

A fork of Dungeon Crawl Stone Soup 0.19.5.

Downloads are on the [Releases](../../releases) page:

- **Linux** — `dungeon-crawl-burgs-edition-1.2-linux-x86_64.tar.gz`
  Extract anywhere and run `crawl`. Nothing to install; all libraries are
  built in. Requires a 64-bit desktop with glibc 2.38 or newer
  (Linux Mint 22, Ubuntu 24.04, Fedora 39, Debian 13, or newer).
  Run `install-launcher.sh` once to add it to your applications menu.

- **Windows** — `dungeon-crawl-burgs-edition-1.2-windows-x64.zip`
  Extract anywhere and run `crawl-tiles.exe` for the graphical version, or
  `crawl-console.exe` for the text version. Nothing to install.

- **Source** — `dungeon-crawl-burgs-edition-1.2-source.tar.gz`
  Complete source code. See `BUILDING.txt` inside for build instructions.

Saves are written next to the game, so keep the extracted folder together.
